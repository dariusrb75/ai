# Serpent Chromatique

Mini-jeu HTML5 façon Slither.io : déplacez votre serpent, avalez des orbes colorées et évitez de vous mordre la queue. Le boost augmente la vitesse en échange de longueur.

## Lancer le jeu

1. Ouvrez `index.html` dans votre navigateur préféré (aucune dépendance ni serveur requis).
2. Contrôles :
   - Flèches ou ZQSD pour diriger le serpent.
   - Espace pour activer le boost (réduit progressivement la taille).
   - R ou le bouton « Recommencer » pour relancer une partie.

Le score et la longueur s'affichent en direct dans le HUD. Le jeu rebondit sur les murs et s'arrête en cas de collision avec votre propre queue.
